Description

Ce projet consistait à créer une serre connectée.

Composants électroniques

La serre utilise plusieurs composants électroniques reliés à un microcontrôleur ESP32 :
- ESP32 (microcontrôleur principal)
- Capteur pression / température (BMP280)
- Capteur qualité de l’air (TVOC / CO₂)
- Capteur de luminosité
- Capteur température / humidité
- Pompe 12V
- Relais de commande
- Capteur niveau réservoir (prévu)

Compétences développées

L’objectif du projet est de créer une serre connectée capable de gérer automatiquement les besoins d’une plante grâce à plusieurs capteurs et un système d’arrosage intelligent.
La serre doit pouvoir :
- surveiller l’environnement en temps réel,
- arroser automatiquement selon l’humidité,
- afficher les données sur une interface web,
- évoluer vers une gestion assistée par IA.
L’utilisateur n’a qu’à remplir le réservoir d’eau : la serre s’occupe du reste.
